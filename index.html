Akkhara Programming Language

ဘာကြောင့် Akkhara Lang ကို တီထွင်ခဲ့တာလဲ?

နိုင်ငံတော်တော်များများက English ကို အခြေခံပြီး programming language တွေဖန်တီးခဲ့ကြပါတယ်။ if, while, function လိုမျိုး keyword တွေအားလုံးနီးပါး English စကားလုံးတွေဖြစ်တာကြောင့် programming စလေ့လာမယ့်သူတွေက code မရေးခင် English ကို အရင်ကြိုးစားနားလည်ရတဲ့ အခြေအနေမျိုး ဖြစ်လာတတ်ပါတယ်။

ဒါပေမဲ့ အချို့နိုင်ငံတွေက ကိုယ့်နိုင်ငံရဲ့မိခင်ဘာသာစကားကို အသုံးပြုပြီး ဖန်တီးခဲ့ကြတာတွေလည်းရှိပါတယ်။ ကိုယ့်ဘာသာစကားနဲ့ code ရေးနိုင်ရင် အစပိုင်းလေ့လာသူတွေအတွက် နားလည်ရလွယ်ပြီး programming ကို ပိုနီးကပ်စွာ ခံစားရမယ်လို့ ယုံကြည်ကြလို့ပါပဲ။

  • တရုတ်နိုင်ငံမှာ Wenyan-lang , 易语言 (E Language)။
  • ဂျပန်နိုင်ငံမှာ Nadesiko။
  • ရုရှားနိုင်ငံမှာ 1C:Enterprise။

ဆိုပြီး အသီးသီးတီထွင်ခဲ့ကြပါတယ်။ (အထက်ဖော်ပြပါ lang များသည် တချို့သောတီထွင်မှုများသာဖြစ်သည်။)

"မြန်မာစာနဲ့ ရော programming language တီထွင်လို့မရဘူးလား?" ဆိုတဲ့ အတွေးဝင်လာတယ်။

တခြားနိုင်ငံတွေက သူတို့ဘာသာစကားနဲ့ တီထွင်နိုင်ခဲ့ရင် ကျွန်တော်တို့ မြန်မာစာနဲ့လည်း ဘာကြောင့်မရနိုင်ရမှာလဲ ဆိုတဲ့ မေးခွန်းက စိတ်ထဲက မထွက်သွားပါဘူး။ မြန်မာစာက စာလုံးတွေ အထပ်ထပ်ရေးရတဲ့ စနစ်ဖြစ်လို့ ကွန်ပျူတာနဲ့ ကိုင်တွယ်ဖို့ ခက်မယ်လို့လည်း ထင်ခဲ့မိပါတယ်။

ဒါကြောင့် ရမရသိချင်လို့ စမ်းလုပ်ခဲ့တယ်။ ပြီးပြည့်စုံတဲ့ အဖြေတစ်ခု ဖန်တီးချင်တာထက် "မြန်မာစာနဲ့ code ရေးလို့ရတယ်" ဆိုတာကို လက်တွေ့ပြနိုင်ဖို့၊ နောက်ပိုင်း programming စလေ့လာမယ့် မြန်မာလူငယ်တွေအတွက် မိခင်ဘာသာစကားနဲ့ စတင်နိုင်တဲ့ လမ်းတစ်ခု ဖြစ်လာဖို့ ရည်ရွယ်ပါတယ်။
