Install လုပ်နည်း

အောက်ပါ platform မှ သင်အသုံးပြုသော platform အားရွေးပါ။

Windows Linux macOS macOS (aarch64)

  1. မျှားထိုးသော အရာကို select ရွေး၍ "Enter" ကို နှိပ်ပါ။

  2. Run ကိုနှိပ်ပါ။

  3. Install ကိုနှိပ်ပါ။

  4. Installing ကိုစောင့်ပါ။

  5. အောက်ဖော်ပြပါပုံအတိုင်း တွေ့မြင်ရပါက Installation အောင်မြင်ပါပြီ။

Terminal မှ install လုပ်ရန်

Powershell 
irm https://raw.githubusercontent.com/XhaStudio/Akkhara-Programming-Language/main/scripts/install.ps1 | iex
Bash 
curl -fsSL https://raw.githubusercontent.com/XhaStudio/Akkhara-Programming-Language/main/scripts/install.sh | sh
